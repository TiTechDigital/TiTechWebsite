The module is a flat, zero-build static site. Each language has its own self-contained page: `index.html` (Italian) and `en/index.html` (English), both mirroring structure, markup IDs, `data-8b-*` attributes, and animation hooks so they share the same visual behavior while differing only in text, metadata, and asset paths (`../assets/`). All styles and scripts are inlined inside each HTML file; external dependencies (GSAP 3.13.0 + ScrollTrigger, Lenis 1.3.4, Google Fonts Gabarito/Onest) load from jsDelivr/Google at runtime. Static assets live under `assets/img/` as pre-optimized WebP variants sized per breakpoint (e.g. `hero-700.webp`, `partner-01-480.webp`, `studio-01-wide-1100.webp`) plus SVG logo/favicon. The contact form is client-side only: it validates inputs and opens the user's mailer via `mailto:` to `info@titechdigital.it`. `index.original.html` preserves the unmodified 8B template source for reference. There is no server-side component, build step, or routing layer — deployment is any static host.
